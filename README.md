## 🌟 مميزات النظام

- 🛡️ **تجاوز بنر تحذير جوجل:** التخلص النهائي من إشعار جوجل التحذيري (`"أنشأ هذا التطبيق أحد مستخدمي برمجة تطبيقات Google"`).
- 🔒 **حماية كاملة للكنترول والدرجات من F12:** جلب واستعلام البيانات يحدث على مستوى السيرفر الخلفي؛ ولا يمكن لأي مستخدم رؤية رابط الشيت الأصلي أو باقي درجات الطلاب.
- ⚡ **سرعة استجابة فائقة (0.001 ثانية):** معالجة محصورة بالعمود الأول مع نظام كاش محلي ذكي يقلل اتصالات جوجل ويعطي نتائج فورية.
- ⏱️ **عداد الأمان ضد الضغط (Cooldown Timer):** عداد تنازلي (5 ثوانٍ) لمنع الضغط المتكرر السريع وحماية الاستضافات المجانية مثل InfinityFree من التوقف.
- 🔗 **مُولد رابط النتيجة المباشر:** إمكانية نسخ رابط مباشر لنتيجة الطالب ومشاركته ليعمل فوراً دون الحاجة لإعادة كتابة رقم الجلوس.
- 📱 **تصميم عصري متجاوب 100% مع الهواتف:** هوية بصرية ملكية بالطابع المصري، زر مسح تلقائي `✕` لسهولة الإدخال على الموبايل، وطباعة مخصصة.
- 🏛️ **صفحة رئيسية متكاملة (`index.html`):** تشمل قسم الأخبار، التنويهات المدرسية، وقسم روابط المستندات والتحميلات المباشرة.

## 🚀 دليل التثبيت والتشغيل خطوة بخطوة

### 1️⃣ الخطوة الأولى: تجهيز شيت جوجل (Google Sheets)
1. افتح جدول بيانات جوجل المشتمل على النتائج.
2. اجعل **العمود الأول** دائماً مخصصاً لـ (رقم الجلوس / رقم الطالب).
3. اذهب إلى قائمة **ملف (File) -> مشاركة (Share) -> النشر على الويب (Publish to web)** ثم اضغط **نشر (Publish)**.
4. انسخ معرف الجدول `SPREADSHEET_ID` من رابط الشيت الخاص بك:
   `https://docs.google.com/spreadsheets/d/`**`ضع_المعرف_هنا`**`/edit`  
   *(أو استخدم رابط النشر 2PACX... بالكامل).*

### 2️⃣ الخطوة الثانية: ضبط معرف الشيت في `api.php`
افتح ملف [api.php](file:///f:/laragon/www/noon6/api.php) وعدّل السطر التالي بوضع معرف الشيت الخاص بك:
```php
$SPREADSHEET_ID = "ضع_معرف_شيت_جوجل_هنا";
```

### 3️⃣ الخطوة الثالثة: تخصيص اسم المدرسة في `index.html` و `result.html`
افتح ملفي [index.html](file:///f:/laragon/www/noon6/index.html) و [result.html](file:///f:/laragon/www/noon6/result.html) وعدّل المتغير في بداية قسم الـ Script:
```javascript
const CONFIG = {
    schoolName: "مدرستي",
    departmentName: "مديرية التربية والتعليم",
    academicYear: "2026 / 2027"
};
```

### 4️⃣ الخطوة الرابعة: الرفع على الاستضافة (InfinityFree / cPanel / Hostinger)
1. قم برفع جميع ملفات المشروع إلى مجلد **`htdocs`** أو **`public_html`** في استضافتك.
2. افتح رابط موقعك وستعمل البوابة المدرسية وصفحة النتائج فوراً بنجاح وسرعة فائقة!
